## Persistent memory (ICM)

Use `icm recall "query"` before substantive work to find relevant context.
Store durable decisions, user preferences, resolved errors, and significant
task outcomes with `icm store -t "topic" -c "summary" -i high`.
Use icm's standard topics: `decisions-{project}`, `preferences`,
`errors-resolved`, and `context-{project}`.
Keep memories concise and specific to the project; omit transient logs,
credentials, tokens, and other secrets. Validate recalled facts against the
current code and instructions before relying on them.
